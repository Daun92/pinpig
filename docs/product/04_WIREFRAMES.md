## 0. 공통 레이아웃

### 앱 셸 + 하단 탭바 (TabBar)

```
┌─────────────────────────────────────┐
│                                     │
│         <main> 페이지 영역           │  ← 세로 스크롤, 가로 숨김
│                                     │
├─────────────────────────────────────┤
│                 ┌───┐               │
│  🐷      📋    │ ＋ │    ◔     ⚙   │  ← FAB: -mt-4 돌출 원형
│  오늘    기록   └───┘   분석   설정  │     h-16, max-w-lg 중앙
└─────────────────────────────────────┘
```

**FAB 상태 변화**
| 컨텍스트 | 아이콘 | 동작 |
|----------|--------|------|
| 일반 화면 | ＋ | `/add` 이동 |
| 입력 화면 + 입력 유효 | ✓ | 저장 실행 (`triggerSubmit`) |
| 입력 화면 + 입력 무효 | ＋(비활성) | 없음 |
| 관리 목록 화면 | 비활성(회색) | 없음 |

**헤더 3종**: 최상위 탭 = 제목만(h-14) / 하위 페이지 = `←` + 중앙 제목 + 우측 액션 / 입력 오버레이 = `✕`(h-12)

**인사이트 캐러셀**: 최대 3장, 무한 순환, 좌우 스와이프, 상단 점 인디케이터(활성=알약형). 카드 탭 → 상세 화면(URL 파라미터 맥락 전달).

**상태 분기**
| 상태 | 히어로/캐러셀 표시 |
|------|-------------------|
| 예산 O + 카테고리 예산 O | 사용자 선택 위젯 (최대 3) |
| 예산 O + 카테고리 예산 X | 관심 카테고리 + "카테고리 예산" CTA |
| 예산 X + 전월 데이터 O | 전월 대비 + "예산 설정" CTA |
| 예산 X + 전월 데이터 X | 기록 현황 + (5건 이상 시) 예산 CTA |
| 거래 0건 (첫 사용) | "새로운 시작이에요" + [＋ 첫 기록 남기기] |
| 오늘만 거래 없음 | 시간대·요일별 감성 문구 + [＋ 기록하기] |

**할부/반복 설정 펼침** (3-way 토글)

```
┌ 할부 / 반복 설정 ────────────────────┐
│   [ 없음 | 할부 | 반복 ]             │  ← 할부는 지출일 때만
│                                      │
│  (할부)  2 3 6 10 12 18 24 36 개월   │
│          "월 2,833원씩 납부"          │
│  (반복)  매일 매주 매월 매년          │
│          매월 [ 25 ] 일              │
│               [ 완료 ]               │
└──────────────────────────────────────┘
```

선택 완료된 항목은 금액 아래 **미니 칩**(카테고리/수단/메모 1행, 태그 2행)으로 축소 표시.

## 4. 거래 상세/수정 (TransactionDetailPage `/transaction/:id`)

AddPage와 동일 레이아웃에서 시작하되 모든 값이 채워진 상태. 상세 화면 = 즉시 편집 화면.

```
┌─────────────────────────────────────┐
│ ✕        [ 지출 | 수입 ]       🗑   │  ← 삭제(confirm)
│        ( 1월 7일 · 12:45 )          │  ← 미래 날짜 선택 불가
│              8,500                  │
│               원                    │
│   (🍽️ 식비) (💳 카드) (#점심)       │  ← 미니 칩 (탭하면 펼침)
│                                     │
│  [ 메모 / 태그 수정 ]               │
│                                     │  ← 할부/반복 섹션 없음
├─────────────────────────────────────┤
│   🐷     📋    (✓)    ◔      ⚙    │  ← FAB ✓ = 수정 저장
└─────────────────────────────────────┘
```

별도 화면 `EditTransactionPage`(/transaction/:id/edit): 헤더 자체 "저장" 버튼 + 카테고리 가로 스크롤 + **반복 거래로 등록 토글**(주기 선택) 포함.

## 15. 알림 설정 4종 (`/settings/*-alerts`)

|------|----------|
| 예산 알림 | 임계값 [50/80/100]% 선택 |
| 카테고리별 알림 | 전체 토글 + 카테고리별 on/off·임계값 [70/100]% |
| 반복 거래 알림 | 기본 N일 전(0/1/3/7) + 반복거래별 오버라이드 |
| 결제수단별 알림 | 수단별 on/off·임계값 [70/100]% (수단에 budget 설정 필요) |
