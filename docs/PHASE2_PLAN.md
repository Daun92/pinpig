## 3. 실행 순서 (스테이지별 산출물)

> 원칙: 각 스테이지는 독립 배포·검증 가능한 단위. S2까지는 Windows에서도 가능, S3부터 Mac 필수.

### S0. Mac 환경 준비 (개발 아님)
- `git clone` → Node 18+ → `npm install` → `npm run dev` 동작 확인
- Claude Code 설치 → 리포의 CLAUDE.md·CONTEXT.md로 맥락 복원
- `npx vercel login` — **daunny 계정** (htry2528 아님)
- (권장) `feat/v0.2.4-improvements` → `main` 병합으로 기준선 정리
- **산출물**: 맥에서 dev 서버 구동 스크린샷 1장이면 충분

### S1. Track 0 최소셋 — TestFlight 배포 전 필수
- 에러 추적 (Sentry류) + privacy-friendly 익명 계측 (opt-in·고지 명확히)
- **산출물**: 외부 테스터 유입 첫날부터 D1/D7 리텐션이 쌓이는 상태
- **이유**: 테스터가 생기는 순간부터 데이터가 쌓여야 함. 며칠짜리 작업
- **진행 (2026-09-07, #142)**: 어댑터·동의 UI·이벤트까지 완료. **전송처 미정** — 서비스(PostHog 단일 vs Sentry+Vercel) 결정 후 `registerTelemetryProvider`로 어댑터 1개 추가하면 S1 종료

### S2. 데이터 내구성 — iOS 전환의 물리적 전제
- 자동 로컬 백업 + 복원 UI (Track 1의 "필수 승격" 항목)
- **이유**: iOS WKWebView의 IndexedDB는 저장 공간 압박 시 OS가 삭제 가능. "기록을 잃지 않는다"는 신뢰 축이 iOS에서 깨지는 것을 선제 차단
- **산출물**: 기기 초기화 시나리오에서 복원 성공하는 백업 체계
- **진행**: #141 복원 UI, #142 백업 엔진(체크섬·검증·`BackupStorage` 어댑터·주기 알림·홈 1탭 저장) + 기기 초기화 시나리오 테스트 통과. **웹에서 할 수 있는 S2는 완료.** S3에서 네이티브 어댑터(Capacitor Filesystem → 앱 Documents)만 갈아끼운다

### S3. Capacitor 셸 + TestFlight (한국어 그대로, P-2)
- Apple Developer Program 등록($99/년) → Xcode + Capacitor 래핑 → 네이티브 영역 백업 연결(S2 산출물) → TestFlight 배포
- App Store 심사 대비: 개인정보 라벨(수집 없음이 강점), 금융 카테고리 요건 확인
- **산출물**: 외부 테스터 10~30명이 설치 가능한 TestFlight 링크

### S4. 위젯 MVP (P-3)
- Capacitor 플러그인으로 App Group 저장소에 "남은 예산·하루 가용액" 기록 → SwiftUI 위젯 2종(Small·Medium)이 읽음
- 갱신 전략: 앱 실행 시 push + 자정 타임라인
- **산출물**: 홈 화면에서 앱을 열지 않고 잔액 확인 — "1초 확인"의 최종형

### S5. 수익화 실행
1. 법무 선행: 개인정보처리방침·약관·환불 정책 + 지원 채널 (Track 2)
2. RevenueCat + StoreKit 구독 1 SKU, Small Business Program(수수료 15%)
3. 유료 경계 확정(D2)은 Track 0 데이터 기반
- **산출물**: 위젯·(추후 동기화)이 잠기는 구독 게이트

### 후순위 (트리거 도달 시)
- **i18n 영어 + 글로벌 랜딩**: 한국 리텐션 검증 후 (P-2의 후속)
- **Dexie Cloud PoC → D1 결정**: S5 전 아무 때나
- **웹 결제(MoR)**: D1 결정 + 계정 체계 이후에만 성립
- **잠금화면 위젯·Watch**: v1.1+

## 4. 리스크 메모

- **WKWebView IndexedDB 삭제** — S2가 S3보다 먼저인 이유. 순서 바꾸지 말 것
- **위젯은 Swift 네이티브** — 웹 코드 재사용 불가. App Group 브리지가 유일한 접점
- **기대치 관리** — MAU 5,000 × 전환 3% × 연 2만원 ≈ 연 300만원. 병목은 가격이 아니라 리텐션·채널 (COMMERCIALIZATION 3.4)
- **철학 가드** — 무광고·무판단·local-first(동기화 opt-in) 유지. 유료화 서사 = "사용자에게만 과금하므로 데이터를 누구에게도 팔지 않는다"
